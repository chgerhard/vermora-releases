# Verhaltensregeln

Dieses Repository ist ein Ort für Fragen und Fehlermeldungen zu Vermora. Damit das für alle
angenehm bleibt:

1. **Sachlich und freundlich bleiben.** Keine Beleidigungen, keine Herabsetzung von Personen
   oder Gruppen, keine Belästigung.
2. **Beim Thema bleiben.** Keine Werbung, keine Links zu Finanzprodukten, keine Kauf- oder
   Verkaufsempfehlungen, keine Steuer- oder Rechtsberatung für andere.
3. **Keine persönlichen Daten.** Weder eigene noch fremde – keine Zahlen, Namen, Kontodaten,
   Depotauszüge oder Kontaktdaten Dritter.
4. **Nichts Rechtswidriges.** Keine fremden Inhalte ohne Erlaubnis, keine Schadsoftware, keine
   Anleitungen zum Umgehen der Signaturprüfung.

## Was ich tue, wenn jemand dagegen verstößt

Ich bearbeite, verberge oder lösche Beiträge, die gegen diese Regeln verstoßen, und kann
Konten für dieses Repository sperren. Ich begründe das nicht in jedem Einzelfall.

Hinweise auf Verstöße bitte über *Report content* bei GitHub oder per E-Mail an die Adresse im Impressum von vermora.de.
