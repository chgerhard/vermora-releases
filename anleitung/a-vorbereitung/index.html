    Teil A — Bevor Sie beginnen¶

    A1 Was Vermora ist und wo Ihre Daten liegen¶

    Vermora ist ein Programm für Ihr Wertpapier-Depot.

    Es zeigt Ihnen, was Sie besitzen, was es wert ist und was steuerlich davon zu berichten wäre.

    Der entscheidende Unterschied zu vielen anderen Programmen: Vermora läuft auf Ihrem eigenen Rechner.

    Ihre Daten liegen auf Ihrer eigenen Festplatte. Sie werden nicht an einen Anbieter gesendet. Niemand außer Ihnen sieht sie.

    Daraus folgt eine Verantwortung, die dieser Text ernst nimmt:

    • Sie sichern Ihre Daten. Es gibt keinen Anbieter, der das im Hintergrund für Sie tut. Dafür gibt es das Kapitel „So sichern Sie Ihre Daten" im laufenden Betrieb, und dieses Kapitel ist Pflicht.
    • Sie verwahren den Schlüssel, mit dem Ihre Sicherungen verschlossen werden. Ohne diesen Schlüssel sind Ihre Sicherungen wertlos. Auch dazu sagt jenes Kapitel alles Nötige.
    • Sie entscheiden, wann aktualisiert wird. Das Kapitel „So aktualisieren Sie" zeigt, wie das geht.

    Zwei Wörter, die im Rest des Textes vorkommen, werden hier ein für alle Mal erklärt.

    Container. Ein Container ist ein abgeschlossenes Päckchen. Darin steckt ein Programm samt allem, was es zum Laufen braucht. Das Päckchen läuft auf Ihrem Rechner, ohne sich mit Ihren übrigen Programmen zu vermischen. Vermora wird als solches Päckchen ausgeliefert.

    Container-Umgebung. Das ist das Hilfsprogramm, das solche Päckchen öffnet und laufen lässt. Sie installieren es einmal. Danach denken Sie nicht mehr daran.

    A2 Passt Ihr Rechner?¶

    Gehen Sie diese Liste durch, bevor Sie etwas herunterladen. Das erspart Ihnen eine Enttäuschung nach einer halben Stunde Arbeit.

    Der Prozessor — die wichtigste Frage zuerst¶

    Vermora läuft heute ausschließlich auf Rechnern mit einem Prozessor der Bauart x86_64. Diese Bauart wird auch x64, AMD64 oder Intel 64 genannt. Alle vier Wörter meinen dasselbe.

    Das trifft auf fast alle Windows-Rechner und fast alle Linux-Rechner zu.

    Es trifft nicht zu auf Apple-Rechner mit M1, M2, M3 oder M4 (genannt „Apple Silicon"). Es trifft ebenfalls nicht zu auf Windows-Geräte mit einem Snapdragon-Prozessor.

    Das ist eine Grenze, keine Empfehlung. Auf solchen Geräten startet Vermora nicht. Es startet dort auch nicht langsam — es startet gar nicht.

    Was Sie in diesem Fall tun: Nutzen Sie einen anderen Rechner der Bauart x86_64. Ein gebrauchter Windows- oder Linux-Rechner genügt vollständig.

    So finden Sie die Bauart heraus:

    • Windows: Drücken Sie die Windows-Taste, tippen Sie Systeminformationen, drücken Sie Enter. In der Zeile „Systemtyp" muss x64-basierter PC stehen. Steht dort ARM64-basierter PC, ist Ihr Rechner nicht geeignet.
    • Linux: Öffnen Sie ein Terminal-Fenster und tippen Sie uname -m, dann Enter. Die Antwort muss x86_64 lauten. Lautet sie aarch64 oder arm64, ist der Rechner nicht geeignet.

    Wird beim Start automatisch geprüft

    Das Startprogramm prüft die Bauart selbst, bevor es irgendetwas herunterlädt. Auf einem ungeeigneten Gerät bricht es mit einer verständlichen deutschen Meldung ab, statt später in einem unklaren Fehler zu enden.

    Die übrige Prüfliste¶

    Linux-Fassung Eine der gängigen Ausgaben ab 2023 (Ubuntu, Debian, Fedora, Mint, openSUSE) Terminal, cat /etc/os-release

    Das Startprogramm misst Arbeitsspeicher und Platz selbst. Bei Unterschreitung erscheint eine Warnung mit der gemessenen Zahl und der Frage, ob trotzdem fortgefahren werden soll.

    Virtualisierung — betrifft allein Windows¶

    Windows braucht für Container-Päckchen eine Funktion namens Virtualisierung. Sie ist bei fast allen Rechnern ab Werk eingeschaltet.

    • Was Sie sehen: Öffnen Sie den Task-Manager (Strg + Umschalt + Esc), Reiter „Leistung", links „CPU".
    • Was das bedeutet: Rechts unten steht eine Zeile „Virtualisierung".
    • Was Sie tun: Steht dort Aktiviert, ist alles gut. Steht dort Deaktiviert, lesen Sie im Kapitel „Wenn etwas nicht klappt" das Symptom zur Virtualisierung.

    Schutz Ihres Datenordners, wenn eine Festplatte das Haus verlässt¶

    Vermora verschlüsselt die Datenbankdatei nicht selbst. Wer Ihre Festplatte in die Hand bekommt, könnte sie lesen. Dieser Fall tritt ein, wenn eine Platte defekt ist und eingeschickt wird, wenn Sie den Rechner verkaufen oder entsorgen, oder bei einem Diebstahl.

    Für den Schutz sind Sie zuständig. Sie haben zwei gleichwertige Wege:

    • Geräteverschlüsselung. Sie schalten die Verschlüsselung des Laufwerks in Ihrem Betriebssystem ein. Danach ist der Datenordner ohne Ihr Passwort unlesbar.
    • Eine feste Regel. Sie legen für sich fest: „Kein Datenträger verlässt das Haus unvernichtet." Defekte oder ausgemusterte Platten zerstören Sie, statt sie zurückzuschicken, zu verkaufen oder wegzuwerfen.

    Beides schützt vor demselben Fall. Wählen Sie, was zu Ihrem Alltag passt, und halten Sie die Wahl fest, am besten schriftlich.

    A3 Was kostet was¶

    Vermora selbst — siehe die Preisangabe auf der Bereitstellungsseite.

    Die Container-Umgebung — hier müssen Sie eine Entscheidung treffen, und sie hat eine Kostenseite. Deshalb steht sie hier und nicht versteckt im Kleingedruckten.

    Es gibt vier Container-Umgebungen. Alle vier funktionieren mit Vermora.

    Umgebung Kosten Anmerkung
    Docker Desktop Für private Nutzung kostenfrei. Kostenpflichtig für Unternehmen ab 250 Mitarbeitern oder ab 10 Millionen US-Dollar Jahresumsatz. Die am weitesten verbreitete Umgebung.
    Rancher Desktop Kostenfrei, quelloffen Bedienung sehr ähnlich zu Docker Desktop.
    Podman Desktop Kostenfrei, quelloffen Braucht unter Windows einen zusätzlichen Startschritt.
    Docker CE Kostenfrei, quelloffen Wird über die Kommandozeile bedient, kein Fenster.

    Diese vier stehen gleichrangig nebeneinander. Diese Anleitung nennt jeweils eine Umgebung als durchgeführten Weg, damit Sie eine klare Spur haben. Die anderen drei sind deshalb nicht schlechter.

    Was Sie tun: Nutzen Sie Vermora zu Hause für Ihr eigenes Depot, wählen Sie Docker Desktop; für die private Nutzung ist es kostenfrei. Die Lizenzbedingungen von Docker Desktop gelten unabhängig von Vermora. Setzen Sie Docker Desktop in einem Unternehmen der oben genannten Größe ein, prüfen Sie dort dessen Bedingungen oder wählen Sie eine der anderen drei.

    A4 Was Sie am Ende haben werden¶

    Damit Sie wissen, wann Sie fertig sind — drei Dinge:

    1. Eine Anmeldeseite in Ihrem Browser. Sie erreichen sie über eine Adresse, die mit https://localhost: beginnt. Sie melden sich dort mit Ihrem eigenen Passwort an.
    2. Zwei Ordner auf Ihrer Festplatte, die Sie selbst ausgesucht haben: einen für Ihre Sicherungen und einen für Ihren Schlüssel. Warum es zwei getrennte Ordner sind, erklären die Windows- bzw. Linux-Kapitel.
    3. Ein Startsymbol, das Sie doppelt anklicken, wenn Sie Vermora benutzen möchten.

    Rechnen Sie beim ersten Mal mit 30 bis 60 Minuten. Der größte Teil davon ist Wartezeit, in der Ihr Rechner etwas herunterlädt. Danach dauert ein Start etwa eine Minute.
