    Vermora einrichten¶

    Diese Anleitung führt Sie Schritt für Schritt durch die erste Installation von Vermora auf Ihrem eigenen Rechner. Nichts wird vorausgesetzt. Jeder Fachbegriff wird an der Stelle erklärt, an der er zum ersten Mal vorkommt.

    So lesen Sie diese Anleitung¶

    Sie lesen einen von zwei Wegen, nicht beide.

    • Sie arbeiten an einem Windows-Rechner → „Bevor Sie beginnen", dann „Der Weg unter Windows", dann „Der laufende Betrieb" bis „Andere Betriebswege".
    • Sie arbeiten an einem Linux-Rechner → „Bevor Sie beginnen", dann „Der Weg unter Linux", dann „Der laufende Betrieb" bis „Andere Betriebswege".

    Die Windows- und die Linux-Kapitel stehen vollständig für sich. Sie müssen im jeweils anderen Kapitel nie nachschlagen.

    Jeder Schritt ist gleich aufgebaut:

    1. Was Sie sehen.
    2. Was das bedeutet.
    3. Was Sie tun.

    Wenn etwas anderes auf dem Bildschirm steht als hier beschrieben, springen Sie zu „Wenn etwas nicht klappt". Dort ist nach dem sortiert, was Sie sehen — nicht nach Ursachen.

    Fassungsstand

    Diese Anleitung ist geprüft für Vermora in der Fassung, die oben auf jeder Seite als Fußzeile steht. Weicht Ihre Fassung deutlich ab, kann sich die eine oder andere Bildschirmmeldung leicht anders lesen — der Ablauf bleibt derselbe.
